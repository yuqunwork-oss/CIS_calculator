# CIS DPI & Scan Time Calculator

JIDIEN 中和碁電 CIS 相機換算工具，單一網頁，不需要安裝。

## 功能

| 工具 | 輸入 | 結果 |
|---|---|---|
| DPI 換算 | DPI、掃描寬度 | 像素大小、像素數、幾 K、可抓瑕疵大小 |
| 反算 DPI | 幾 K、掃描寬度 | DPI（1K = 1,000 / 1,024）、像素大小、可抓瑕疵大小 |
| 掃描時間 | DPI、行頻、掃描長度 | 掃描速度、掃描線數、掃描時間 |

## 公式

- 像素大小（mm）= 25.4 ÷ DPI
- 像素數 = 寬度 ÷ 25.4 × DPI
- DPI = 像素數 ÷（寬度 ÷ 25.4）
- 掃描速度 = 行頻 × 像素大小
- 掃描時間 = 掃描長度 ÷ 掃描速度
